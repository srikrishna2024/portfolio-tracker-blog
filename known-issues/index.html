Fixed in recent releases

✅ Fixed Fixed in v7.2.1

Browser does not open automatically after Start App.bat

run.py 👥 1 reporter

What happens: After Start App.bat runs, browser does not open. App runs fine but --server.headless true suppresses Streamlits auto-open and run.py did not call webbrowser.open().

Fixed in v7.2.1. Update the app to get this fix — go to Admin → Upgrade.

✅ Fixed Fixed in v7.2.1

Upgrade launcher buttons hidden — window too small on some screen resolutions

launcher/windows/upgrade_launcher.pyw 👥 1 reporter

What happens: The upgrade launcher window height (700px) is not tall enough on some screens. The pre-flight checklist fills the window and Refresh Checks / Start Upgrade buttons are hidden below the visible area. Users cannot proceed with the upgrade.

Fixed in v7.2.1. Update the app to get this fix — go to Admin → Upgrade.

✅ Fixed Fixed in v7.2.1

CAMS PDF parser picks up noise as scheme names — Demat), merger notes, (Non Demat) appear in import

shared/debt_statement_parsers.py _parse_cams_pdf 👥 1 reporter

What happens: Some CAMS statements include tags like (Non Demat), fund merger notes like Treasury Plan merged), or fragment text like Demat) in the scheme listing. Parser picks these up as scheme names, failing AMFI code match — NAV = 0, portfolio value understated.

Fixed in v7.2.1. Update the app to get this fix — go to Admin → Upgrade.

✅ Fixed Fixed in v7.2.1

Restore fails on PostgreSQL 18 — --single-transaction incompatible with --create

1_Admin_Tools/new_backup.py do_restore restore_type=1clean 👥 1 reporter

What happens: pg_restore fails on PostgreSQL 18 when using Restore to this machine. PostgreSQL 16+ does not allow --single-transaction combined with --create.

Fixed in v7.2.1. Update the app to get this fix — go to Admin → Upgrade.

How to report a new issue

If your issue is not listed here:

  1. Open the software and go to Admin → Report a Bug
  2. Fill in the form — it automatically collects your app version, OS, and error log
  3. Download the generated report and email it with any screenshots to support@personalfinanceapp.in

Critical bugs are responded to the same day. Non-critical bugs are fixed in the next scheduled release.
