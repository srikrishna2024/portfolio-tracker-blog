Common Questions

Everything you need to know before getting started.

🖥️ Do I need any technical knowledge to use this?

No. Setup takes about 20 minutes and the software walks you through each step. If you can install software and follow instructions, you can set it up. A Setup Wizard inside the software handles configuration automatically.

📂 Which statements and brokers are supported?

For mutual funds: CAMS PDF, MF Central PDF, and MF Central Excel. For debt instruments: EPF (UMANG app PDF), NPS (NSDL CRA statement), PPF (account statement PDF), and Superannuation (major provider formats). Stocks can be imported via CSV.

📶 Does it work without an internet connection?

Yes, almost entirely. The software, all calculations, and all analysis work fully offline. Internet is only needed when you choose to update fund prices (from AMFI's public website) or when you use the optional AI features.

🗄️ Where is my data stored?

On your own computer, in a local database that only the software can access. There is no cloud backup, no sync to any server, and no third party involved. You can back up your data yourself and restore it to a new machine at any time.

💾 What if my laptop is lost or my hard disk crashes?

Since your data lives only on your machine, it is your responsibility to back it up regularly. The software has a one-click Backup option under Admin that creates a single file containing your entire financial history. Take a backup after every import or major update and copy it to Google Drive, OneDrive, or an external drive. If something happens to your machine, you can restore from that file on a new one in minutes. Treat your backup file the same way you treat important financial documents.

🤖 What are the AI features and are they mandatory?

AI features let you ask questions about your portfolio in plain English and generate goal recommendations and annual review summaries. They are completely optional and the software works fully without them. If you enable them, you need an Anthropic API key (available free with usage limits).

🔒 If I enable AI, what data gets sent?

Only portfolio structure: fund names, values, goal names and amounts. Account numbers, PAN, Aadhaar, and bank details are never stored in the software's database to begin with, so they cannot be sent anywhere. You can review exactly what is included before any AI call is made.

💻 Does it work on Windows and Mac?

Yes, both are supported. Windows 10/11 (64-bit) and macOS 12 or newer. The software and launcher are separate builds for each platform.

📤 What happens to my data if I stop using the software?

Your data stays on your machine. It does not disappear or get deleted. You can export your transaction history at any time. There is no subscription that expires and takes your data with it.

🛡️ My antivirus flagged the software. Is it safe?

Yes. The software's compiled files trigger a false positive on BitDefender and a small number of related products. BitDefender's security team has reviewed the files and confirmed they are clean. The detection will be removed in their next update. 59 out of 67 antivirus engines are clean, including Windows Defender, Kaspersky, and Sophos. The Setup Wizard in the software has step-by-step instructions for adding an exclusion in each product.
