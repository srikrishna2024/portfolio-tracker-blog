Getting Started

From purchase to your first portfolio health score. A complete step-by-step guide.

⏱️ Total time: about 20–30 minutes, mostly waiting for downloads

Before You Begin

You will need two free programs installed on your computer before the software will work. Download and install them first. The setup wizard inside the software checks for both.

🐍
Python 3.14 or newer

Download from python.org. Run the installer.

Windows: on the first screen, tick "Add Python to PATH" before clicking Install.

Mac: download the macOS .pkg installer and run it, or use Homebrew: brew install python@3.14

🗄️
PostgreSQL 13 or newer

Download from postgresql.org. Run the installer and click Next on every screen keeping all defaults.

On the Password screen, set a password for the postgres superuser. Write it down. The Setup Wizard asks for it once.

Leave the port as 5432 (default). You do not need to open pgAdmin.

Stack Builder: After the installer finishes, a window called Stack Builder may appear. Click Cancel — you don't need anything from it. The database is already installed.

🌐
A web browser

Chrome, Edge, Firefox, or Safari. The software opens in your browser at a local address. No browser account or sign-in is required. It connects to your own machine, not the internet.

🛡️ Antivirus notice: The software is clean — All 67 antivirus engines on VirusTotal gave it a clean pass. If your AV flags the file, update your AV definitions and re-scan, or add the app folder as an exclusion. Step-by-step instructions are in the Setup Wizard. See the FAQ for more detail.
1

Unzip the download

⏱️ 2 minutes

Unzip the file to a permanent folder on your computer. Choose a location where it will stay — do not leave it in Downloads.

🪟 Windows

Right-click the zip → Extract All → when asked for destination, type C:\ and click Extract. This creates C:\pages_app_vX_X_X_windows\ automatically. Then rename that folder to C:\pages_app for a shorter name.

⚠️ Common mistake — double-nested folder: Do not extract into an existing folder like C:\pages_app\. If you do, files end up at C:\pages_app\pages_app_vX_X_X_windows\ — a double-nested path that Windows shortens internally and breaks the app with an ImportError on startup.

Fix if this happened: Open C:\pages_app\pages_app_vX_X_X_windows\, select all (Ctrl+A), cut (Ctrl+X), paste into C:\pages_app\, delete the empty subfolder, then re-run Run Setup.bat.
🍎 Mac

Suggested location: ~/pages_app

Double-click the zip file to extract it.

2

Run the Setup tool

⏱️ 5 minutes

Open the launcher\windows\ folder and double-click Run Setup.bat. A setup window opens and asks for four things:

📧 License email The email address you used when purchasing
🔑 License key Shown in the purchase confirmation email
🗄️ PostgreSQL password The password you wrote down during PostgreSQL installation
🔐 Reset passphrase Create one yourself (e.g. MyFinance2025) and write it down

Click Test DB Connection first to confirm PostgreSQL is reachable. Once it shows a green tick, click Run Setup. It installs packages, saves your credentials, and creates the database automatically. When it shows "Setup Complete", close the window.

If double-clicking Run Setup.bat opens and closes immediately, see the Known Issues page for the fix.

3

Launch the app and apply any pending updates

⏱️ 2 minutes

🪟 Windows
  1. Double-click Start DB.bat — click Yes when Windows asks for permission
  2. Double-click Start App.bat — your browser opens automatically at http://localhost:8501

If the browser doesn't open, go to http://localhost:8501 manually and bookmark it.

🍎 Mac
  1. First time only: double-click setup_mac_permissions.command
  2. Double-click start_db.command
  3. Double-click start_app.command

Once the app is open, go to Admin Tools → Setup Wizard. If you see a yellow "Schema updates pending" banner, click ▶ Apply Now. This takes under a minute and ensures all features work correctly. If no banner appears, skip to the next step.

4

Load fund data

⏱️ 2 min (from backup) or 10–20 min (download)

Before importing your portfolio, the software needs the full list of fund schemes and historical NAV prices.

Option 1 — From backup files (faster, recommended):
You received two files with your welcome email: fund_master_data.dump and nav_history.dump. Go to Admin Tools → Backup → Restore tab.

  1. Upload fund_master_data.dump → select "Load fund prices from a backup" → click Restore. Wait for Fund master row count to show ~16,000 ✅
  2. Upload nav_history.dump → select "Load fund prices from a backup" → click Restore. Wait for NAV history row count to show 1,000,000+ ✅
Always use "Load fund prices from a backup" for these files — not "Restore to this machine". The wrong restore type will overwrite your personal data.

Option 2 — Download fresh (if you don't have the backup files):
Go to NAV Data Manager → Data Pipeline → Weekly Maintenance. Takes 10–20 min on first run.

5

Import your portfolio

⏱️ 5 minutes

Go to Data Import and import your statements.

📄 Mutual funds

Go to Data Import → Equity Import. Upload your CAMS PDF or MF Central PDF / Excel. Review the preview, then confirm import.

CAMS → camsonline.com | MF Central → mfcentral.com → CAS Download

🏦 EPF / NPS / PPF / Super

Go to Data Import → Debt Import. Each tab handles one instrument type.

EPF: UMANG app PDF | NPS: NSDL CRA statement | PPF: bank statement PDF

If something looks wrong after importing (wrong fund names, missing values), use the Reset Equity Portfolio Data option at the bottom of the Equity Import page to clear and re-import cleanly.

6

Create your goals

⏱️ 5 minutes

  1. Go to Goal Planning → Create a Goal
  2. Describe each goal in plain English — e.g. "Save ₹50 lakhs for my daughter's college in 12 years" or "Build a ₹2 crore retirement corpus in 20 years"
  3. Review the details the software fills in, then save
  4. Repeat for each financial goal you want to track
7

Assign your funds to goals

⏱️ 5 minutes

Do not skip this step. Without it, the Goal Dashboard, health score, and SIP adequacy check show no meaningful data.
  1. Go to Goal Planning → Goal Fund Manager
  2. For each fund, select which goal it is saving towards
  3. A single fund can be split across multiple goals by percentage

Once done, open Goal Planning → Goal Dashboard to see your health score and how each goal is tracking.

🎉

You are set up

Your portfolio is imported, your goals are mapped, and your health score is live. The app is now working for you in the background — you do not need to check it every day.

Suggested Routine — Less Is More

⚠️ Don't check your Goal Dashboard daily. Market prices change every day — that is noise, not signal. Checking daily leads to reacting to short-term moves, which hurts long-term compounding through unnecessary switching and tax costs.

When you open the app on any day — NAV update only

🪟 Windows
  1. Double-click Start DB.bat
  2. Double-click Start App.bat
  3. NAV Data Manager → Data Pipeline → Daily Refresh
  4. When done: Stop App.bat then Stop DB.bat
🍎 Mac
  1. Double-click start_db.command
  2. Double-click start_app.command
  3. NAV Data Manager → Data Pipeline → Daily Refresh
  4. When done: stop_app.command then stop_db.command

Once a quarter — quick check

Open Alerts → Alert Center and scan for red alerts. If everything is green, close the app. If a goal shows "At Risk", open Goal Dashboard to understand why. That's it.

Once a year — April is the right time

April is the best time: the financial year has just closed and you likely have a salary revision ahead.

  1. Goal Diagnostics — run the health score; review sub-scores and K4/K8 for each goal
  2. Goal Dashboard — act only on what the "What to do now" widget flags
  3. Tax Optimizer — review your LTCG position; book gains up to ₹1.25L if not already done
  4. Goal Fund Manager — reassign any funds whose goal has changed
  5. Step up your SIPs by at least the inflation rate (5–7%) if your income has grown

When your life changes

These events warrant an immediate review regardless of calendar: new job or salary change, new goal (child's education, home purchase), a goal achieved, or a major expense coming in the next 2–3 years.

💾 Back up your data regularly. Go to Admin → Backup after any major import or update, and copy the backup file to Google Drive, OneDrive, or an external drive. Your data lives only on your machine. If the drive fails without a backup, the data cannot be recovered.
