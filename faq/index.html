Common Questions

Everything you need to know before getting started.

🖥️ Do I need any technical knowledge to use this?

No. Setup takes about 20 minutes and the software walks you through each step. If you can install software and follow instructions, you can set it up. A Setup Wizard inside the software handles configuration automatically.

📂 Which statements and brokers are supported?

For mutual funds: CAMS PDF, MF Central PDF, and MF Central Excel. For debt instruments: EPF (UMANG app PDF), NPS (NSDL CRA statement), PPF (account statement PDF), and Superannuation (major provider formats). Stocks can be imported via CSV.

📶 Does it work without an internet connection?

Yes, almost entirely. The software, all calculations, and all analysis work fully offline. Internet is only needed when you choose to update fund prices (from AMFI's public website) or when you use the optional AI features.

🗄️ Where is my data stored?

On your own computer, in a local database that only the software can access. There is no cloud backup, no sync to any server, and no third party involved. You can back up your data yourself and restore it to a new machine at any time.

💾 What if my laptop is lost or my hard disk crashes?

Since your data lives only on your machine, it is your responsibility to back it up regularly. The software has a one-click Backup option under Admin that creates a single file containing your entire financial history. Take a backup after every import or major update and copy it to Google Drive, OneDrive, or an external drive. If something happens to your machine, you can restore from that file on a new one in minutes. Treat your backup file the same way you treat important financial documents.

🤖 What are the AI features and are they mandatory?

AI features let you ask questions about your portfolio in plain English and generate goal recommendations and annual review summaries. They are completely optional and the software works fully without them. If you enable them, you need an Anthropic API key (available free with usage limits).

🔒 If I enable AI, what data gets sent?

Only portfolio structure: fund names, values, goal names and amounts. Account numbers, PAN, Aadhaar, and bank details are never stored in the software's database to begin with, so they cannot be sent anywhere. You can review exactly what is included before any AI call is made.

💻 Does it work on Windows and Mac?

Yes, both are supported. Windows 10/11 (64-bit) and macOS 12 or newer. The software and launcher are separate builds for each platform.

📤 What happens to my data if I stop using the software?

Your data stays on your machine. It does not disappear or get deleted. You can export your transaction history at any time. There is no subscription that expires and takes your data with it.

🛡️ My antivirus flagged the software. Is it safe?

Yes. All 67 antivirus engines on VirusTotal gave it a clean pass — including Windows Defender, Kaspersky, Sophos, McAfee, BitDefender, ESET, Avast, and AVG. If your AV ever flags the file, update your AV definitions and re-scan. The Setup Wizard includes step-by-step instructions for adding a folder exclusion in any product.

📊 The Portfolio Analysis page shows a very high Debt Value — much more than what I actually hold. Why?

Portfolio Analysis shows all debt — your debt mutual funds (like money market, gilt, or short-duration funds) plus your EPF/NPS/PPF instruments. The Debt & Fixed Income Tracker shows only the manual instruments (EPF/NPS/PPF). The difference is your debt mutual funds. If the number still looks too high, go to Goal Planning → Goal Fund Manager → Fix Fund Types — some funds may be incorrectly tagged as Debt when they are actually equity index funds or ETFs.

🔄 I reassigned a fund to a different goal but the old goal is now showing an inflated value. What happened?

This was a bug fixed in v7.5.1. After a reassignment, a stale record was left behind in the database and was being counted twice in the goal's value calculation. After updating, the old goal's value will show correctly. To update, download the latest version from your Google Drive link and run the upgrade.

🎯 I cannot see the Retirement goal in the Re-assign dropdown. How do I assign funds to it?

The Retirement goal is managed separately from all other goals. Go to Retirement Planning → Retirement Planner → Fund Mapping to assign funds to your retirement goal. Once done, use Goal Fund Manager → Re-assign / Remove → Remove mapping entirely to remove those funds from any other goals they were previously assigned to.

📅 My PPF statement upload fails with "Unrecognised date" errors. What format should dates be in?

The software accepts DD-MM-YYYY (e.g. 28-08-2021), DD-MM-YY (e.g. 28-08-21), DD/MM/YYYY, and DD-Mon-YYYY (e.g. 28-Aug-2021). If your CSV uses a different format, open it in Excel, select the date column, and reformat it to DD-MM-YYYY before uploading. Note: if both day and month are 12 or below (e.g. 12-01-12), the software assumes DD-MM-YY, which is the standard Indian date format.

🏦 How do I create an Emergency Fund goal that does not have a target date?

Name your goal "Emergency Fund", "Contingency Fund", or "Liquid Reserve" when creating it — the software automatically marks it as a perpetual goal with no target date. No timeline question is asked, no SIP estimate is shown, and the goal shows "♾️ Perpetual" instead of years remaining. On the Goal Dashboard you will see an "Update target to current value" button to keep the target in sync with your actual corpus.

👨‍👩‍👧 My spouse and I both invest in the same funds. Importing both statements removes the duplicates. How do I handle this?

This is a known limitation — the duplicate detection uses date + fund code + units, so identical investments by two people on the same date get merged. The workaround is to import one person's statement first, then add the second person's overlapping transactions manually via the Transactions tab. Multi-member portfolio support (each member's transactions tracked separately) is on the roadmap.

📥 What is the best way to upload my statement for the first time, and how do I update it each year?

Upload your complete statement from inception to today the first time — not just the current year. XIRR and return calculations need the full transaction history to be accurate. Each year after that, download a full statement again (from start to today) and upload it. Duplicates from previous uploads are automatically skipped, so re-uploading the full history is safe. AMFI code remapping only needs to be done once per fund, not on every upload.

🔄 After I upload my CAMS/NSDL statement the first time, how do I handle monthly updates when I have bought or sold funds?

Just re-import. Go to Data Import → Equity Import, upload your new monthly statement (full history or just recent transactions), and the software automatically skips anything that already exists in the database — it only inserts transactions it has not seen before. No manual tracking needed. The duplicate detection matches on date + fund code + units, so re-uploading a full statement is completely safe. Most users download a fresh CAMS statement once a month and upload it — the whole process takes under a minute.

📊 Can the software show my data across all asset classes together — direct equity, equity MFs, debt MFs, and hybrid all grouped?

Partial support today. The Portfolio Analysis page shows your MF portfolio split by category (equity / debt / hybrid) with current values, allocation percentages, and XIRR per category. The Debt & Fixed Income Tracker covers EPF, NPS, PPF, and FDs alongside debt MFs, and the Goal Dashboard shows the equity vs debt split per goal. What is not yet available is a single consolidated screen that adds direct equity stocks + equity MFs + debt MFs + EPF into one allocation pie — that is on the roadmap as the Net Worth Tracker feature.

🔗 Does the software show mutual fund overlaps so I can decide whether to consolidate two funds into one?

Yes — the My Portfolio → Correlation page shows an inter-fund correlation heatmap. Funds with correlation above 0.85 are flagged as largely redundant: they move together, so holding both gives little diversification benefit. The page ranks the most correlated pairs so you can make a consolidation decision. For example, if two large-cap funds show 0.90 correlation in your portfolio, you are effectively doubling up on the same exposure. What the current version does not show is stock-level overlap (e.g. “both funds hold HDFC Bank at 8% each”) — that would require AMC factsheet data. For most investors the correlation heatmap is sufficient to identify redundancy.
