📦 What gets installed

The software installs two components on your machine:

  • The main interface: the main interface you use daily, opens in your browser at a local address
  • A local database: stores all your financial data on your machine. This is what keeps your data private. No data leaves your computer.

Both components are installed during the setup process, guided step by step by the Setup Wizard inside the software. You do not need to configure anything manually.

📋 Software prerequisites

The following free software needs to be installed before running the software. The Setup Wizard checks for each one and links you to the installer if missing.

  • Python 3.14 or newer: free, available from python.org. The Setup Wizard checks the version and will tell you if it is wrong.
  • A local database engine: free, the Setup Wizard guides installation
  • A modern web browser: Chrome, Edge, Firefox, or Safari (any recent version). The software opens in your browser at a local address. No browser account or sign-in is required.

If you are not comfortable installing software, get in touch before purchasing. Setup typically takes 20 minutes for someone doing it for the first time.

🛡️ Antivirus

The software is clean — All 67 antivirus engines on VirusTotal gave it a clean pass, including Windows Defender, Kaspersky, Sophos, McAfee, BitDefender, ESET, Avast, and AVG. If your AV flags the file, update your AV definitions and re-scan. The Setup Wizard includes step-by-step instructions for adding an exclusion. See the FAQ for more detail.
