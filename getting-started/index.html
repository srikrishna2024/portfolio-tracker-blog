Getting Started

From purchase to your first portfolio health score — a complete step-by-step guide.

⏱️ Total time: about 20–30 minutes, mostly waiting for downloads

Before You Begin

You will need two free programs installed on your computer before the software will work. Download and install them first — the setup wizard inside the software checks for both.

🐍
Python 3.11 or newer

The software runs on Python. Download from python.org. Run the installer and tick "Add Python to PATH" before clicking Install.

🗄️
PostgreSQL 13 or newer

The local database that stores your financial data. Download from postgresql.org. Run the installer with all defaults. Write down the password you set — you will need it once during setup.

🌐
A web browser

Chrome, Edge, Firefox, or Safari. The software opens in your browser at a local address. No browser account or sign-in is required — it is connecting to your own machine, not the internet.

🛡️ Antivirus notice: Some antivirus programs may flag the software files when you unzip the download. This is a confirmed false positive — BitDefender's security team has verified the files are clean. Before unzipping, add the destination folder as an exclusion in your antivirus. Step-by-step instructions for Windows Defender, BitDefender, and others are in the Setup Wizard inside the software. See the FAQ for more detail.
1

Unzip the download

⏱️ 2 minutes

Unzip the file you received to a permanent folder on your computer. Choose a location where it will stay — not your Downloads folder.

🪟 Windows

Suggested location: C:\pages_app

Right-click the zip file → Extract All → choose the destination.

🍎 Mac

Suggested location: your home folder → ~/pages_app

Double-click the zip file to extract it.

2

Launch the software

⏱️ 2 minutes

Inside the extracted folder, open the launcher folder for your platform.

🪟 Windows

Open launcher\windows\

  1. Double-click Start DB.bat — Windows will ask for permission, click Yes
  2. Double-click Start App.bat — your browser opens automatically

If the .bat files flash and disappear, use launch.pyw instead — a graphical window with Start / Stop buttons.

🍎 Mac

Open launcher/mac/

  1. First time only: double-click setup_mac_permissions.command (right-click → Open if Mac blocks it)
  2. Double-click start_db.command
  3. Double-click start_app.command — your browser opens automatically

If the .command files won't open, use launch_gui.command instead.

Your browser opens at http://localhost:8501. You will see the Home page. This address is your own computer — nothing is going to the internet.

3

Run the Setup Wizard

⏱️ 5 minutes

From the Home page, click Admin → Setup Wizard. The wizard asks for four things:

📧 License email The email address you used when purchasing
🔑 License key Shown in the purchase confirmation email
🗄️ PostgreSQL password The password you wrote down during PostgreSQL installation
🔐 Reset passphrase Create one yourself (e.g. MyFinance2025) and write it down — this protects your settings page

Click Begin Setup. The wizard runs five steps automatically and shows a green tick for each one. If any step fails, the message tells you exactly what to fix. The most common cause is a wrong PostgreSQL password — re-enter it and try again.

4

Download fund data

⏱️ 10–20 minutes (mostly waiting)

Before you can import your portfolio, the software needs to download the full list of mutual fund schemes and their historical NAV prices from AMFI. This happens once and takes 10–20 minutes depending on your internet speed.

  1. Go to NAV Data Manager → Data Pipeline
  2. Click Weekly Maintenance
  3. A progress bar shows each step. Wait for it to complete.

After this first download, daily updates take 2–5 minutes using the Daily Refresh button on the same page.

5

Import your portfolio

⏱️ 5 minutes

Go to Data Import and import your statements.

📄 Mutual funds

Go to Data Import → Equity Import. Upload your CAMS PDF or MF Central PDF / Excel. The software reads all your transactions automatically. Review the preview, then confirm.

To download your statement: CAMS → camsonline.com | MF Central → mfcentral.com → CAS Download

🏦 EPF / NPS / PPF / Super

Go to Data Import → Debt Import. Each tab handles one instrument type. Upload the statement PDF or CSV from your provider.

EPF: UMANG app PDF | NPS: NSDL CRA statement | PPF: account statement PDF

6

Set up your goals

⏱️ 5 minutes

  1. Go to Goal Planning → Create a Goal
  2. Describe each goal in plain English — for example: "Save ₹50 lakhs for my daughter's college in 12 years" or "Build a ₹2 crore retirement corpus in 20 years"
  3. Go to Goal Planning → Goal Fund Manager and map your funds to each goal
  4. Open Goal Planning → Goal Dashboard to see your portfolio health score
🎉

You are set up

Your portfolio is imported, your goals are mapped, and your health score is live. From here, your daily routine is simple: start the software, click Daily Refresh, and check your dashboard.

Your Daily Routine

🪟 Windows — every day
  1. Double-click Start DB.bat
  2. Double-click Start App.bat
  3. NAV Data Manager → Data Pipeline → Daily Refresh
  4. Check Goal Planning → Goal Dashboard
  5. When done: Stop App.bat then Stop DB.bat
🍎 Mac — every day
  1. Double-click start_db.command
  2. Double-click start_app.command
  3. NAV Data Manager → Data Pipeline → Daily Refresh
  4. Check Goal Planning → Goal Dashboard
  5. When done: stop_app.command then stop_db.command
💾 Back up your data regularly. Go to Admin → Backup after any major import or update, and copy the backup file to Google Drive, OneDrive, or an external drive. Your data lives only on your machine — if the drive fails without a backup, the data cannot be recovered.
